Carousel / Slider Component
Vanilla JS
Single file implementation

HTML + CSS + JavaScript (Vanilla JS)
All three are written inside a single file.

HTML defines:

* Slider container
* Slides
* Images
* Navigation dots

CSS controls:

* Layout
* animation
* shadows
* dots styling
* slider size
* fonts

JavaScript handles:

* Slide movement
* Auto sliding
* Dot navigation
* Drag/swipe interaction
* Touch support
